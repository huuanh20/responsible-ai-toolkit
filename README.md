# Responsible AI Toolkit for Office Users

> **FWD IT Internship Portfolio Project** · Nguyen Huu Anh · 2026

A practical, interactive web-based guide helping **non-technical employees** adopt AI tools safely, ethically, and effectively in the workplace.

**🔗 Live Demo:** [huuanh20.github.io/responsible-ai-toolkit](https://huuanh20.github.io/responsible-ai-toolkit)  
**👤 Author:** [Nguyen Huu Anh](https://github.com/huuanh20)

---

## 🎯 Project Overview

This project directly addresses the key responsibilities of the **IT Governance & Security** role:

| JD Requirement | What I Built |
|---|---|
| *"Create simple AI user guides for non-technical users"* | Quick Reference Guides section (6 cards) |
| *"Draft, test, and improve prompts for common tasks"* | Prompt Library (20+ curated prompts) |
| *"Support Responsible AI / data governance work"* | FAQ (10 topics) + 5-Step Safety Framework |
| *"Research industry trends and best practices for AI"* | Content based on EU AI Act & Google Responsible AI |

---

## ✨ Features

- 🌙 **Modern dark UI** — professional, corporate-ready design
- 📋 **20+ Office Prompts** — copy-ready for emails, reports, analysis, meetings
- ❓ **10-item Interactive FAQ** — accordion UI covering common AI concerns
- 🛡️ **5-Step Safety Framework** — simple checklist for responsible AI use
- 📱 **Responsive** — works on desktop and mobile
